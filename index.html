Code ↗ Models ↗ Datasets ↗

One Model. Every Move. 是一个面向通用人形机器人研发的 5B VLA，使用约 2,500 小时高质量真机数据和大规模通用 VLM 数据联合训练。模型以交互为中心进行世界建模，单模型能力覆盖桌面操作、移动操作、蹲起与行走，并支持二指夹爪和不同类型的五指灵巧手。

ER Model · Embodied Reasoner

理解交互，
预测变化。

ER 模型基于 Qwen3-VL-4B 构建。超过 300 万条训练数据覆盖图像点预测、目标检测、多图推理、2D 轨迹预测、3D 目标检测和多图空间问答，并与通用图文数据混合训练。模型在保持通用视觉语言能力的同时，提升了具身场景中的空间理解与推理能力。

DYNAMIC WORLD MODELING

Dynamic region prediction

我们利用光流定位未来会发生变化的区域，将动态区域转换为二值 mask，并通过 VQ-VAE 离散为固定数量的 token。VLM 根据当前图像与任务描述或动作，直接预测未来动态区域对应的 mask token。

02 / Method
VLA Model · Shared Policy

多本体数据，
同一个模型。

VLA 使用约 2,500 小时、覆盖多种机器人本体与场景的真机数据。数据处理统一了末端坐标系与动作空间，模型结构基于 Unifolm-VLM-Flow 和 MMDiT 动作专家。VLA 预训练阶段同步混合通用 VLM 数据，持续保持视觉语言模型的通用能力。
